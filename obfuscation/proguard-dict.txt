# Obfuscation dictionary for a Bukkit/Paper plugin.
#
# ProGuard draws replacement names for classes, packages and members from this list instead of its
# default a, b, c, aa, ab ... sequence. Every entry below is a legal *bytecode* identifier but an
# ILLEGAL *Java source* identifier (reserved words, or already-used-up short names), so a decompiler
# that turns the jar back into .java either refuses the name or has to mangle it — the output no
# longer compiles and is far harder to read. The JVM itself does not care: it never parses these as
# source. Lines starting with # and blank lines are ignored; duplicates are used once each.
#
# This is a readability attack on the decompiler, not encryption. It raises the cost of reversing the
# jar; it does not make it impossible. See README.md.
